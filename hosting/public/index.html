BEFORE YOUR PROMPT LEAVES

One pause. Three choices.

When SecretGuard finds possible secrets, it shows the detected values so you can decide what to share.

  1. 01

    Send

    Send the original prompt with detected values unchanged. This unmasked send attempt is saved in local History.

  2. 02

    Edit

    Return to your draft and make changes before sending.

  3. 03

    Mask

    Replace detected values with xxxxxxxxxx and activate the chat website’s send control.
