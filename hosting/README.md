# SecretGuard website

Static homepage, Privacy Policy, and Terms and Conditions for SecretGuard 2.0.0 by Hunasys. The site uses a symmetric rounded orbit logo with a filled white-to-light-silver gradient for Hunasys, the shield/keyhole icon for the SecretGuard product, locally served DM Sans, a black background, white accents, and graphite panels. These files are separate from the extension ZIP. No Firebase SDK, analytics, database, payment service, or server is required.

## Published pages

- Home: https://secretguard-hunasys.web.app
- Privacy Policy: https://secretguard-hunasys.web.app/privacy-policy
- Terms and Conditions: https://secretguard-hunasys.web.app/terms-and-conditions
- The previous `/privacy` address redirects permanently to `/privacy-policy` so existing links keep working.
- The previous `/terms` address redirects permanently to `/terms-and-conditions`.
- Firebase project and Hosting site: `secretguard-hunasys`

## Update and deploy

Use Node 24 LTS and the official Firebase CLI. Authenticate with `firebase login` if necessary. From this `hosting/` directory:

```sh
firebase hosting:sites:list --project secretguard-hunasys
firebase deploy --only hosting --project secretguard-hunasys
```

Verify that the listed site is `projects/secretguard-hunasys/sites/secretguard-hunasys` before deploying. `firebase.json` explicitly selects that site and uploads only `public/`. Do not deploy to the previous `ckretguard` site or the separate AgentGuard project. Test the public URLs on desktop and mobile after any change. Fonts and icons are served locally; preserve their bundled license files when updating them. The homepage uses a static illustrative secret review and does not collect or submit prompts.

The Hunasys master is `artifacts/branding/orbit-dark-background/hunasys-symmetric-silver.svg`. Run `node artifacts/branding/orbit-dark-background/export-symmetric-logo.mjs` from the repository root to reproduce the website SVG, transparent PNG and 32-pixel PNG favicon. Both sides of the opening use mirrored geometry and the same 42-unit gap from the pointer in a 1024-unit canvas. SVG and PNG backgrounds, central hole and gaps are transparent. Pages use `?v=symmetric-1` logo URLs to refresh cached images, the tab title `SecretGuard`, and the homepage label `SecretGuard by Hunasys`.

The homepage's 217-rule count refers to the active prompt-compatible Gitleaks catalog. Five filename-dependent rules are excluded. This count does not promise full Gitleaks feature parity, credential validation, or detection of every secret; see `docs/GITLEAKS.md` for the implementation scope and reference tests.

The SecretGuard product icon (`public/ckretguard.png`) uses the approved pointed shield with straight, sloping upper edges, a white outline and a white keyhole with a narrow neck. The shield fills the canvas height with 28:32 proportions; the keyhole circle stays round. It is copied from `extension/icons/ckretguard-128.png`, generated by `artifacts/branding/secretguard-selected/export-toolbar.mjs`. Product image references use `?v=shield-tall-20261103` to refresh older cached icons. The Hunasys company logo and transparent favicon remain separate assets.

This website deployment does not change URLs embedded in the extension or fields in the Chrome Web Store dashboard. Those existing URLs remain as they were until a separate update is requested.

Publishing these website pages does not publish or submit the Chrome extension. The documents describe SecretGuard 2.0.0: local scanning, 90-day unmasked-send History without extension encryption, local settings and counters, no production debug logger, nine supported chat providers, and support at connect.hunasys@gmail.com. Update their text and revision dates when those practices or terms change. No Firebase credentials belong in this directory or in Git.
